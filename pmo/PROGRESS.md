# 제작 진행 기록

기획서: PMO 일감 트래킹·알림 시스템 v0.1 (10장 제작 순서 기준)

## 실행 방법
```
cd pmo
pip install -r requirements.txt
python app.py        # http://localhost:5000
```
데이터는 `pmo/data/pmo.db`(SQLite)에 저장됩니다. 지우면 처음 상태로 돌아갑니다.

## 구조
| 파일 | 역할 |
| --- | --- |
| app.py | 화면별 동작 (S1~S7) |
| db.py | 데이터 구조(4장의 8가지 대상 + 접근 기록), 샘플 사용자 |
| auth.py | 로그인. 지금은 가짜 로그인이고, 2단계에서 이 파일만 SSO로 교체 |
| templates/, static/ | 화면. 색상은 기존 B tv 대시보드에서 가져옴 |

## 순서 1 — 완료 (F1 임시, F2)
- 가짜 로그인: 샘플 사용자 6명 중 골라 들어감 (김피엠·이피엠 = 시스템 관리자)
- 로그인하지 않고 주소를 열면 로그인 화면으로 이동
- 프로젝트 만들기·수정·삭제 (시스템 관리자만). 만든 사람은 자동으로 프로젝트 관리자
- 등록되지 않은 사람에게는 프로젝트가 보이지 않음 (주소로 직접 열어도 404)
- 상단 메뉴: 프로젝트 / 알림함(안 읽은 수) / 내 설정. 알림함·내 설정은 자리만 있음
- 프로젝트 생성·수정·삭제 기록은 audit_log에 남음

**확인 방법:** 김피엠으로 들어가 프로젝트를 만들면 목록에 보이고, 최개발로 들어가면 보이지 않는다.

## 순서 2 — 완료 (F3)
- 프로젝트 화면의 "설정 · 멤버"(S4)에서 멤버 추가·제거, 역할 변경
- 역할은 프로젝트 관리자 / 멤버 두 가지 (열람자는 2차, 11장 8번 기본안)
- 시스템 관리자와 그 프로젝트의 관리자만 멤버를 바꿀 수 있음 (다른 프로젝트는 손댈 수 없음)
- 마지막 프로젝트 관리자는 제거하거나 멤버로 내릴 수 없음
- 추가하면 바로 프로젝트가 보이고, 제거하면 바로 안 보임
- 멤버 추가·제거·역할 변경 기록이 audit_log에 남음

**확인 방법:** 김피엠으로 프로젝트에 최개발을 추가한 뒤 최개발로 들어가면 그 프로젝트만 보인다. 제거하면 사라진다.
